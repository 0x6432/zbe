# Extern/GOT foundation — work in progress

This is an unreviewed draft, based on integration draft `3890562118b85be550dcc19f6c400414d3f8672a`. That base has not passed its fresh local integration gate or terminal audit; its exact-commit CI is running. This branch is not production acceptance or a complete extern/GOT implementation.

Current work adds a module-owned `got_symbol` IR operand, conservative decoded-symbol eligibility and an allocation-free eligibility scan after generic and aggregate checks. Scalar-only modules are scanned before the existing empty-plan return. Contextual extern value and call syntax and dedicated/wrapped call-target identity are implemented in the draft. The interpreter refuses reached GOT operands/calls. The AMD64 emitter now loads addresses from GOTPCREL and performs indirect calls; this new implementation is still unreviewed and not fully validated.

Focused tests covered operand, eligibility, call identity, parser behavior and allocation cleanup: 8/8 passed separately in Debug, ReleaseSafe and ReleaseFast. The naming helper also passed focused Debug tests. A Debug native smoke passed 32 combinations (8 code-generation options, 2 linker settings, provider/preload), including scalar and two small/large record call cases; a GOT-slot-address mutant was rejected. These are not the full loader or compatibility ledger. Full three-mode testing, the existing compatibility matrices, independent reviews, secondary calibration audit, terminal audit and exact-commit CI for this new tree remain outstanding. No release, canonical advancement, ABI parity or complete compiler claim is made.

Independent static review of `a7997a535e9e7f121833bac49b85ac914ebd6873` identified incorrect interpreter refusal for new call targets and missing declaration-position diagnostics. This work-in-progress corrects both, with a 31-case exact-byte-span diagnostic table and ordering tests for standalone/module-owned calls, poisoned GOT arguments/ENV, step/depth limits and both target forms. Ten focused Debug tests passed under the shared lock; broader coverage and independent review of the corrected tree remain outstanding. Earlier focused runs were not consistently taken under the specified shared lock and are not acceptance evidence.

A separate focused native ABI smoke exercises seven GP arguments, nine FP arguments and a nine-FP variadic call against independent C providers, both ordinary and preempted, with an AL=0 runtime negative control. Default and all-flags Debug cases passed; other modes/options and the full ABI ledger are not yet proven. The focused smoke tools are registered in the draft rewrite CI; this registration has not yet run on this tree.
